# ДораТехно — контрольная работа №4

Интерактивная версия многостраничного интернет-магазина по теме «JavaScript: интерактивность, DOM, события, формы и валидация».

Проект `kr4-js-shop` создан на основе адаптивного HTML/CSS-сайта контрольной работы №3 `kr3-responsive-shop`. В КР №4 сохранены главная страница, разделы каталога с боковыми фильтрами и сравнительными таблицами, страницы товаров, контакты, изображения и адаптивная вёрстка. Карточки каталога теперь создаёт JavaScript.

## Реализованные возможности

- массив из девяти товаров с единой структурой данных;
- генерация карточек каталога через `document.createElement()`;
- безопасный вывод данных через `textContent`;
- поиск по названию товара;
- фильтрация по категории, наличию и избранному;
- дополнительные фильтры КР №3: диапазон цен и характеристики внутри каждой категории;
- сортировка карточек внутри категорий по цене, названию и рейтингу;
- счётчик найденных товаров и пустое состояние каталога;
- добавление товара при переходе по исходной ссылке «Открыть корзину»;
- изменение количества и удаление товаров;
- расчёт стоимости корзины через `reduce()`;
- промокод `DORA10` со скидкой 10%, которая учитывается в форме заявки;
- сохранение корзины, избранного и промокода в `localStorage`;
- при первом открытии корзины показаны три демонстрационных товара из КР №3; после очистки они не появляются повторно;
- выбор в заявке отдельного товара или текущей корзины;
- базовая валидация формы заявки;
- сообщения об ошибках рядом с полями без `alert()`;
- сохранение последних учебных заявок в `localStorage` без имени, e-mail и телефона; до первой заявки показаны три демонстрационные записи из КР №3;
- поддержка клавиатуры, `aria-live`, `aria-invalid` и `aria-describedby`.

## JavaScript-файлы

| Файл | Назначение |
| --- | --- |
| `js/data.js` | Массив товаров, поиск товара по `id`, форматирование цены |
| `js/storage.js` | Корзина, избранное и безопасная работа с `localStorage` |
| `js/main.js` | Общая инициализация и поведение страниц товаров |
| `js/home.js` | Управление каруселью главной страницы и исходными ссылками корзины |
| `js/catalog.js` | Поиск, фильтрация, сортировка, DOM-рендер карточек и события каталога |
| `js/cart.js` | Вывод корзины, количество, удаление, промокод и расчёт итоговой суммы |
| `js/validation.js` | Заполнение списка товаров и валидация формы заявки |
| `js/contact.js` | Демонстрационное подтверждение формы обращения после встроенной проверки браузера; данные не отправляются на сервер |

## Самостоятельные доработки

Помимо обязательной части КР №4 реализованы:

- полноценная корзина с добавлением, удалением и изменением количества;
- автоматический пересчёт суммы через `reduce()`;
- промокод и пересчёт скидки;
- сохранение корзины и промокода в `localStorage`;
- избранное с отдельным фильтром и сохранением состояния;
- добавление товара через исходные ссылки карточек и страниц товаров без изменения их оформления;
- выбор отдельного товара или всей корзины в заявке;
- локальное подтверждение формы контактов без отправки данных на сервер;
- сохранение учебной истории заявок без контактных данных и показ демонстрационных карточек КР №3 до первой заявки;
- работа боковых фильтров КР №3 и обновление сравнительных таблиц;
- понятные пустые состояния и сообщения интерфейса.
