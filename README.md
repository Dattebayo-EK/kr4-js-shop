# ДораТехно — контрольная работа №4

Многостраничный учебный интернет-магазин. Контрольная работа №4 продолжает адаптивный сайт КР3: сохранены его страницы и визуальная основа, а каталог, корзина, избранное и формы дополнены JavaScript.

## Сайт

После включения GitHub Pages сайт доступен по адресу:

**https://dattebayo-ek.github.io/kr4-js-shop/**

Главная страница проекта — `index.html` в корне репозитория. Ссылки на страницы, CSS, JavaScript и изображения заданы относительно папки проекта, поэтому они работают в репозитории GitHub Pages с путём `/kr4-js-shop/`.

### Как включить GitHub Pages

1. Откройте репозиторий [Dattebayo-EK/kr4-js-shop](https://github.com/Dattebayo-EK/kr4-js-shop).
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку **main** и папку **/(root)**, затем нажмите **Save**.
5. Дождитесь завершения публикации в разделе Pages и откройте ссылку выше.

Сборка и установка зависимостей не нужны: GitHub Pages публикует HTML, CSS, JavaScript и изображения прямо из корня репозитория. Если после публикации видна старая версия, проверьте последний запуск публикации в **Actions**, затем обновите страницу без кэша.

## Возможности

- каталог из девяти товаров с поиском, сортировкой и фильтрами;
- боковые фильтры по цене и характеристикам, унаследованные от КР3;
- создание карточек каталога через DOM и безопасный вывод текста через `textContent`;
- избранное и фильтр «Только избранное»;
- корзина с изменением количества, удалением и пересчётом суммы;
- промокод `DORA10` со скидкой 10%;
- сохранение корзины, избранного, промокода и учебной истории в `localStorage` браузера;
- проверка формы заявки и демонстрационное подтверждение формы контактов;
- адаптивная вёрстка страниц проекта.

## Где хранятся данные

Сайт работает без backend. Корзина, избранное, промокод и история учебных заявок сохраняются в `localStorage` браузера для текущего адреса сайта. Эти данные остаются на устройстве и не синхронизируются с другими браузерами. Контактные данные из формы заявки не сохраняются. Форма контактов только показывает подтверждение и никуда не отправляет текст обращения.

| Ключ `localStorage` | Что хранится |
| --- | --- |
| `dora-shop-cart` | Массив позиций корзины `{ id, quantity }` |
| `dora-shop-favorites` | Массив идентификаторов избранных товаров |
| `dora-shop-promo` | Код `DORA10` или пустая строка |
| `dora-shop-orders` | До 10 учебных заявок без имени, телефона и e-mail |

При первом открытии корзина и история показывают демонстрационные данные, похожие на исходные карточки КР3. После очистки корзины примерные позиции повторно не добавляются.

## JavaScript-файлы

| Файл | Назначение |
| --- | --- |
| `js/data.js` | Массив товаров, поиск товара по `id`, форматирование цены |
| `js/storage.js` | Корзина, избранное, промокод и работа с `localStorage` |
| `js/main.js` | Общая интерактивность и ссылки на страницах товаров |
| `js/home.js` | Карусель и карточки главной страницы |
| `js/catalog.js` | Поиск, фильтры, сортировка, создание карточек каталога |
| `js/cart.js` | Отображение корзины, количество, промокод и итоговая сумма |
| `js/validation.js` | Выбор состава заявки, проверка полей и локальная история |
| `js/contact.js` | Подтверждение формы контактов без отправки на сервер |

Скрипты подключены в HTML с атрибутом `defer`, поэтому браузер сначала разбирает разметку, а затем запускает JavaScript в порядке подключения.

## Локальный запуск

Для проверки на компьютере откройте терминал в папке проекта и запустите статический сервер:

```bash
python -m http.server 8000
```

Затем перейдите по адресу `http://localhost:8000/`. Сборка проекта и установка пакетов не требуются.

## Проверка основных сценариев

1. В каталоге проверьте поиск, категорию, сортировку, боковые фильтры и пустой результат.
2. Добавьте товар в избранное и включите фильтр избранного.
3. Добавьте товар в корзину, измените количество, удалите позицию и обновите страницу.
4. Примените `DORA10` и проверьте пересчёт суммы.
5. В форме заявки проверьте сообщения для пустых и неправильных полей, затем отправьте корректную учебную заявку.
6. Откройте инструменты разработчика браузера и проверьте Console и `Application → Local Storage`.
